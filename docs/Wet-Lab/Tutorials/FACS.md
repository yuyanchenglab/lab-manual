## CHOP Flowcytometry Core Laboratory
At this time, we use the sorters in the CHOP Flowcytometry Core for our FACS experiments. Training sessions and instrument reservations are made in [iLab](https://med-upenn.corefacilities.org/sc/4691/flow-cytometry-core-laboratory/?tab=about). Please refer to the core's iLab page for specifics. 

#### Instruments
For most FACS experiments we use the FACSAria-1 Fusion which has a 405 laser in addition to a 488, 561, and 640. The FACSAria-2 does not have a 405 laser so can not be used in experiments that include a live/dead stain such as DAPI.
* FACSAria-1 Fusion (ARC 1207 H, 4 lasers, 15 colors)
* FACSAria-2 (ARC 1207 H, 3 lasers, 8 colors)

#### Training
Before booking a semi-assisted session, researchers must complete training with core staff. Please see the iLab page for more details.

#### Facility Access
Researchers from Penn can [apply for a CHOP token](https://content.ilabsolutions.com/wp-content/uploads/2025/01/How_to_Obtain_A_CHOP_Token_rev.pdf) to get access to CHOP building from 8AM to 6PM. If you do not have facility access, you will need to check in with the security officer in the lobby.

#### PO/Payment Information
1. Ask Joy to generate a PO for the CHOP Flowcytometry Core BenBuys information (Phila 200, Site 49513, Children's Hospital of Philadelphia)
2. Upload the PO in iLab on the Flowcytometry Core page
3. Once the PO is approved/active you will be able to reserve instruments in iLab

## Results / Output
FACS run files should be saves in '.fcs' format which can be analyzed in FlowJo or a similar software. Export any recordings as 'pdf'. Save results/output files in the respective project folder on Box.
